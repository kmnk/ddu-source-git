INTRODUCTION			*ddu-source-git_log_files-introduction*

This source collects files changed in a specific git commit and lists them
in ddu.vim. Each item represents one changed file with its status code
(M, A, D, R100, etc.). The accompanying kind provides file open operations.

Typically opened from the `files` action of the `git_log` kind.


==============================================================================
INSTALL				*ddu-source-git_log_files-install*

Use your plugin manager to install this plugin.

Requirements:
- ddu.vim (https://github.com/Shougo/ddu.vim)
- denops.vim (https://github.com/vim-denops/denops.vim)
- git command available in PATH


==============================================================================
SOURCE				*ddu-source-git_log_files-source*

git_log_files
		Collects files changed in a commit from
		`git show --name-status --format= <hash>` output.
		Each item displays the status code followed by the file path.
		For renamed/copied files the display is
		`<statusCode>  <old> -> <new>`.

		`item.word` is the destination file path (relative).
		`item.action.text` is the relative path — used as yank target.
		`item.action.path` is the absolute path — used for open/tabopen.

		Highlights applied per item:

		  git_log_files-status   The status code at the beginning of
		                         each line. Highlight group depends on
		                         the status: A→added, D→deleted,
		                         R/C→renamed, others→modified.

			*ddu-source-git_log_files-source-params*
PARAMS ~

hash		(string)
		The full or abbreviated commit hash to inspect.
		If empty, no items are collected.
		Default: ""

cwd		(string)
		Working directory for the git command.
		If empty, uses the current working directory from context.
		Default: ""

highlights	(object)
		Highlight group names for each status category.

		highlights.added    (string)
			Highlight for added files (A status).
			Default: "diffAdded"

		highlights.modified (string)
			Highlight for modified files (M and other statuses).
			Default: "diffChanged"

		highlights.deleted  (string)
			Highlight for deleted files (D status).
			Default: "diffRemoved"

		highlights.renamed  (string)
			Highlight for renamed or copied files (R/C status).
			Default: "diffChanged"


==============================================================================
KIND				*ddu-kind-git_log_files*

git_log_files
		Kind for git log files items. Provides file open operations.
		`item.word` is the relative file path (destination for renames).

			*ddu-kind-git_log_files-actions*
ACTIONS ~

yank
		Yank the relative file path (`item.word`) to the unnamed
		register.

open
		Open the file in the current window with `:edit`.

tabopen
		Open the file in a new tab with `:tabedit`.


==============================================================================
EXAMPLES			*ddu-source-git_log_files-examples*

>vim
	" Opened automatically from git_log files action.
	" Direct usage:
	call ddu#start(#{
	  \   sources: [#{
	  \     name: 'git_log_files',
	  \     params: #{hash: 'abc1234', cwd: '/path/to/repo'},
	  \   }],
	  \ })

	" Set default action to open
	call ddu#custom#patch_global(#{
	  \   kindOptions: #{
	  \     git_log_files: #{
	  \       defaultAction: 'open',
	  \     },
	  \   },
	  \ })

	" Key mappings in ddu UI (ddu-ui-ff)
	autocmd FileType ddu-ff call s:ddu_ff_my_settings()
	function s:ddu_ff_my_settings() abort
	  if b:ddu_ui_name ==# 'git_log_files'
	    nnoremap <buffer> <CR>
	      \ <Cmd>call ddu#ui#do_action('itemAction', #{name: 'open'})<CR>
	    nnoremap <buffer> t
	      \ <Cmd>call ddu#ui#do_action('itemAction', #{name: 'tabopen'})<CR>
	  endif
	endfunction
<
