INTRODUCTION				*ddu-source-git_branch-introduction*

This source collects git branches and lists them in ddu.vim.
The accompanying kind provides actions to operate on branches.


==============================================================================
INSTALL					*ddu-source-git_branch-install*

Use your plugin manager to install this plugin.

Requirements:
- ddu.vim (https://github.com/Shougo/ddu.vim)
- denops.vim (https://github.com/vim-denops/denops.vim)
- git command available in PATH

SOURCE					*ddu-source-git_branch-source*

git_branch
		Collects branches from `git branch` output.
		The current branch is marked with "*" prefix.
		Branches checked out in a linked worktree are marked
		with "+" prefix.

				*ddu-source-git_branch-source-params*
PARAMS ~

args		(string[])
		Additional arguments passed to `git branch`.
		For example, ["--all"] to include remote branches,
		or ["--remotes"] for remote-only branches.
		Default: []

cwd		(string)
		Working directory for the git command.
		If empty, uses the current working directory from context.
		Default: ""

highlights	(object)
		Highlight group names for branch display.

		highlights.current  (string)
			Highlight applied to the current branch line.
			Default: "Statement"

		highlights.remote   (string)
			Highlight applied to remote branch names.
			Default: "Comment"

		highlights.worktree (string)
			Highlight applied to branches checked out in a
			linked worktree (displayed with "+" prefix).
			Default: "Special"


==============================================================================
KIND					*ddu-kind-git_branch*

git_branch
		Kind for git branch items. Provides branch operations.

				*ddu-kind-git_branch-params*
PARAMS ~

remote		(string)
		The remote name used for push, pushForce, and fetch actions.
		Default: "origin"

				*ddu-kind-git_branch-actions*
ACTIONS ~

yank
		Yank the branch name to the unnamed register.

switch
		Switch to the selected branch using `git switch`.
		Skips if the selected branch is already the current branch.

create
		Prompt for a new branch name, then create it from the
		selected branch and switch to it (`git switch -c`).

delete
		Delete the selected branch with `git branch -d`.
		Skips the current branch. Refreshes the ddu list on success.

deleteForce
		Force delete the selected branch with `git branch -D` after
		confirmation. Skips the current branch.
		Refreshes the ddu list on success.

rebase
		Rebase the current branch onto the selected branch using
		`git rebase`. Skips if the selected branch is the current
		branch.

rebaseInteractive
		Start an interactive rebase of the current branch onto the
		selected branch (`git rebase -i`) in a `:terminal` buffer.
		Skips if the selected branch is the current branch.

move
		Prompt for a new name and rename the selected branch with
		`git branch -m`. Refreshes the ddu list on success.

copy
		Prompt for a new name and copy the selected branch with
		`git branch -c`. Refreshes the ddu list on success.

merge
		Merge the selected branch into the current branch with
		`git merge`. Requires confirmation. On failure, the combined
		stdout/stderr is shown in a scratch buffer.

push
		Push the selected branch to the remote specified by the
		`remote` kind param (`git push <remote> <branch>`).

pushForce
		Force-push the selected branch with `--force-with-lease`
		to the remote specified by the `remote` kind param.
		Requires confirmation.

fetch
		Fetch the selected branch from the remote specified by the
		`remote` kind param (`git fetch <remote> <branch>`).

addWorktree
		Create a new worktree for the selected branch.
		Prompts for a path, then runs
		`git worktree add <path> <branch>`.


==============================================================================
EXAMPLES				*ddu-source-git_branch-examples*

>vim
	" Basic usage
	call ddu#start(#{
	  \   sources: [#{name: 'git_branch'}],
	  \ })

	" Include remote branches
	call ddu#start(#{
	  \   sources: [#{
	  \     name: 'git_branch',
	  \     params: #{args: ['--all']},
	  \   }],
	  \ })

	" Set default action to switch
	call ddu#custom#patch_global(#{
	  \   kindOptions: #{
	  \     git_branch: #{
	  \       defaultAction: 'switch',
	  \     },
	  \   },
	  \ })

	" Set remote for push/fetch
	call ddu#custom#patch_global(#{
	  \   kindParams: #{
	  \     git_branch: #{
	  \       remote: 'upstream',
	  \     },
	  \   },
	  \ })
<
